# ParfumWorld (عالم العطور)

تطبيق ويب فاخر مخصص لمحلات العطور، يتيح للزبائن اختيار النوتات العطرية المفضلة واستكشاف العطور المطابقة، بالإضافة إلى لوحة تحكم كاملة للمشرفين لإدارة الكتالوج وتتبع التحليلات.

---

## 🚀 التقنيات المستخدمة (Tech Stack)

* **الواجهة الأمامية**: React 19 + TypeScript + Vite.
* **التصميم والتنسيق**: Tailwind CSS v4 + Lucide Icons (تصميم داكن فاخر Burgundy & Gold).
* **إدارة المسارات**: `react-router-dom`.
* **التعدد اللغوي والاتجاهات**: `react-i18next` لدعم ثلاث لغات (ar, en, fr) مع تبديل تلقائي فوري لاتجاه الصفحة RTL/LTR على مستوى وسم `<html>`.
* **قاعدة البيانات والخدمات**: Supabase (قاعدة بيانات PostgreSQL + نظام المصادقة Supabase Auth + مستودع ملفات Supabase Storage).

## 🗄️ بنية قاعدة البيانات (Supabase Schema & Policies)

تم بناء قاعدة البيانات وتأمينها باستخدام **سياسات الحماية على مستوى الصف (Row-Level Security - RLS)** لضمان عدم تمكن أي مستخدم عادي من التعديل على البيانات:

### 1. الجداول الأساسية
* `admins`: يحتوي على معرفات المشرفين المصرح لهم برفع وتعديل العطور.
* `note_categories`: فئات النوتات العطرية (حمضيات، أخشاب، إلخ).
* `notes`: النوتات العطرية الفردية (رأس، قلب، قاعدة).
* `brands`: الماركات التجارية للعطور.
* `perfumes`: العطور المتوفرة مع الأسعار والروابط البديلة (`is_dupe_of`).
* `perfume_notes`: جدول الربط بين العطور ونوتاتها العطرية مع تحديد الطبقة.
* `wishlists`: لحفظ مفضلة الزبائن ومزامنتها.
* `search_analytics`: لتسجيل تحليلات البحث وتحسين المخزون.
* `store_settings`: الإعدادات العامة للمتجر (رقم واتساب، اسم المتجر، شعاره، ورابط الخرائط).

### 2. وظائف قاعدة البيانات (Database RPCs)
* `match_perfumes`: خوارزمية البحث المخصصة لمطابقة العطور بناءً على النوتات المطلوبة واستبعاد العطور التي تحتوي على أي نوتة مستبعدة (`excluded_note_ids`).
* `get_top_searched_notes`: تجميع تحليلات النوتات الأكثر بحثاً.
* `get_failed_searches`: تتبع عمليات البحث التي لم تسفر عن نتائج لتوسيع خيارات المتجر.
* `get_out_of_stock_demand`: معرفة العطور النافذة الأكثر طلباً من الزبائن.

## 🎨 ميزات التطبيق المتقدمة

1. **مستكشف النوتات المتطور (Note Picker)**:
   - تحديد النوتات المفضلة (تطابق تصاعدي) واستبعاد النوتات المزعجة (فلترة استبعاد نهائي).
2. **الاختبار العطري السريع (Scent Quiz)**:
   - اختبار تفاعلي بـ 4 أسئلة ذكية يقترح فوراً نوتات عطرية تطابق تفضيلات المستخدم.
3. **مقارنة العطور جنباً إلى جنب (Scent Comparison)**:
   - مقارنة عطرين بشكل تفصيلي من حيث الحجم، السعر، التركيز، النوتات المشتركة، والنوتات المميزة لكل عطر.
4. **المفضلة والمزامنة الذكية**:
   - حفظ المفضلة محلياً، مع إمكانية المزامنة السحابية عبر الأجهزة بمجرد تسجيل الدخول الاختياري بالبريد الإلكتروني (Magic Link بدون كلمات مرور).
5. **شريط بديل عطور قانوني وآمن**:
   - إظهار بدائل العطور بصيغة تسويقية لبقة وقانونية: `"مستوحى من روح [اسم العطر]"`.
6. **لوحة تحكم الإدارة المحمية (`/admin`)**:
   - تحليلات تفصيلية، إضافة وتعديل وحذف العطور مع رفع الصور وتحديد طبقات النوتات، وتعديل إعدادات المتجر العامة.

## 💻 التشغيل المحلي والتطوير

### 1. إعداد المتغيرات البيئية
أنشئ ملف `.env.local` في المجلد الرئيسي للمشروع وأضف المتغيرات التالية:
```env
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

### 2. تثبيت المكتبات والتشغيل
```bash
# تثبيت الاعتماديات
npm install

# تشغيل خادم التطوير المحلي
npm run dev

# بناء النسخة الإنتاجية
npm run build
```

## 🚀 النشر والإنتاج على Vercel

عند نشر التطبيق على منصة **Vercel**:

1. اربط مستودع الـ GitHub الخاص بالمشروع بـ Vercel.
2. أضف متغيرات البيئة (`VITE_SUPABASE_URL` و `VITE_SUPABASE_ANON_KEY`) في لوحة تحكم المشروع على Vercel (تحت إعدادات Environment Variables).
3. تأكد من أن متغيرات البيئة في Vercel مطابقة للمشروع الإنتاجي في Supabase (`Production Project`) وليس أي بيانات تجريبية محلية.
4. يقوم Vercel تلقائياً بقراءة ملف `vercel.json` لتفعيل الـ Routing الخاص بـ Single Page Application لمنع ظهور أخطاء `404` عند إعادة تحميل الصفحات الداخلية.
